1)String literal
-In Java, a string literal is a sequence of characters enclosed in double quotes (").
-It is used to represent a string value in your Java code. 
-String literals are instances of the String class.

String greeting = "Hello, world!";

Immutable: String literals are immutable, meaning once created, their values cannot be changed.

Stored in String Pool: Java maintains a String pool in memory where string literals are stored to save memory.
 If a new string literal already exists in the pool, the same reference is used.
 
String name = "John";
String message = "Hello, " + name + "!";

2)What is static and dynamic binding
-Static binding : Static Binding (also known as Early Binding) in Java occurs when the method call is resolved at compile time.
-It happens when the compiler can determine the method to call based on the reference type.
Static binding applies to:
-Static methods
-Private methods
-Final methods
-Method overloading (not overriding)

-Dynamic Binding (also known as Late Binding) occurs when the method to be called is determined at runtime.
-It is used in the context of method overriding and polymorphism.
Dynamic binding occurs when:
A non-static, non-final, and non-private method is overridden in a subclass.
The method call is made on a parent class reference that points to a child class object.

3)What is throw and throws
-throw :The throw keyword is used to manually throw an exception
-It is used inside a method or block.
-It must be followed by an instance of Throwable (like Exception, RuntimeException, etc).

public class Test {
    public static void main(String[] args) {
        int age = 15;
        if (age < 18) {
            throw new ArithmeticException("Age must be 18 or older");
        }
    }
}

-throws :- The throws keyword is used in the method signature to declare that the method might throw an exception.
-Mostly used for checked exceptions (like IOException, SQLException).

import java.io.IOException;
public class Test {
    public static void main(String[] args) throws IOException {
        checkFile();
    }

    public static void checkFile() throws IOException {
        throw new IOException("File not found");
    }
}

4)What is this and super keyword
-this keyword
- this keyword is used within the class only
-this keyword can be used:
 (a) at variable level
 (b) at method level
 (c) at constructor level
 
 this.variable --> 	Refer to instance variable
 
 class Student {
    String name;

    Student(String name) {
        this.name = name;  // 'this.name' = instance variable, 'name' = parameter
    }

    void printName() {
        System.out.println(this.name);
    }
}
 
 this.method() --> 	Call method in same class
 
 class Demo {
    void display() {
        System.out.println("Hello from display");
    }

    void show() {
        this.display();  // calling current class method
    }
}
 
 this() --> Call another constructor , constructor nesting
 
 class Test {
    Test() {
        this(10);  // calls parameterized constructor
        System.out.println("Default Constructor");
    }

    Test(int x) {
        System.out.println("Parameterized Constructor: " + x);
    }
}
 

-Super keyword
-  super keyword is used in the child class only. super keyword can be used:
 (a) at variable level
 (b) at method level
 (c) at constructor level
 
 (a) at variable level 
 class Animal {
    String type = "Animal";
}

class Dog extends Animal {
    String type = "Dog";

    void printType() {
        System.out.println(super.type);  // Access parent variable
    }
}
 
 (b) at method level
 
 class Animal {
    void sound() {
        System.out.println("Animal makes sound");
    }
}

class Dog extends Animal {
    void sound() {
        super.sound();  // Call parent method
        System.out.println("Dog barks");
    }
}
 
 (c) at constructor level
  
  class Animal {
    Animal(String name) {
        System.out.println("Animal name: " + name);
    }
}

class Dog extends Animal {
    Dog() {
        super("Tiger");  // Call parent constructor
        System.out.println("Dog constructor");
    }
}
  
5)Inheritance in java

-its tell the relationship between parent and child calls 

1.Single Inheritance
class A {
    void msg() {
        System.out.println("Hello from A");
    }
}

class B extends A {
    void show() {
        System.out.println("Hello from B");
    }
}

 2.Multilevel Inheritance
 
 class A {
    void msg() {
        System.out.println("Class A");
    }
}

class B extends A {
    void show() {
        System.out.println("Class B");
    }
}

class C extends B {
    void display() {
        System.out.println("Class C");
    }
}

3.Hierarchical Inheritance
 
 class Animal {
    void eat() {
        System.out.println("Eating...");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking...");
    }
}

class Cat extends Animal {
    void meow() {
        System.out.println("Meowing...");
    }
}
 
4. Multiple Inheritance

Java does not support multiple inheritance with classes (to avoid ambiguity), but you can achieve it using interfaces.

class Animal {
    void eat() {
        System.out.println("Eating...");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking...");
    }
}

class Cat extends Animal {
    void meow() {
        System.out.println("Meowing...");
    }
}
